# Technology-M-A-transaction-research
Excel-based technology M&amp;A transaction research database with source verification and data quality checks.
## 1. PROJECT OVERVIEW

This project focuses on collecting, organizing, and validating publicly available information about mergers and acquisitions involving technology companies. It demonstrates transaction research, source verification, structured data collection, data quality management, and business documentation.

## 2. PROJECT OBJECTIVE

The objective is to build a structured and reliable database of technology M&A transactions by identifying relevant deals, collecting key transaction details, verifying information against credible sources, and maintaining data consistency.

## 3. PROJECT SCOPE

The database records transaction-level information, including:

* Deal ID and transaction status
* Acquirer and target company
* Announcement date and publication date
* Transaction type and deal description
* Transaction value and currency, when disclosed
* Consideration type, when available
* Definitive agreement and closing details, when available
* Source URLs and research notes

## 4. RESEARCH METHODOLOGY

1. Identify publicly announced technology acquisitions.
2. Locate relevant company announcements, press releases, regulatory filings, and credible news reports.
3. Extract transaction details into the structured database.
4. Cross-check important details against available sources.
5. Record source URLs and distinguish confirmed information from undisclosed information.
6. Review the dataset for consistency, completeness, and accuracy.

## 5. DATA QUALITY CHECKS

* Check for duplicate Deal IDs and duplicate transactions.
* Verify announcement dates and publication dates.
* Standardize company names, transaction types, dates, and currencies.
* Check required fields for missing values.
* Validate transaction values and units where disclosed.
* Verify source URLs and retain supporting research notes.
* Mark undisclosed or unavailable information appropriately instead of assuming values.

## 6. DATA SOURCES

Sources used may include:

* Official company press releases and websites
* Regulatory filings and government documents
* Reputable financial news publications
* Other credible public sources relevant to the transaction

Only list sources that were actually used in the project.

## 7. TOOLS USED

Microsoft Excel for structured data entry, organization, filtering, sorting, and data quality checks.

## 8. PROJECT LIMITATIONS

The database is based on publicly available information. Some transactions may not disclose financial terms, consideration details, or closing dates. Information may vary in detail across sources, and undisclosed information is not estimated without supporting evidence.

## 9. PROJECT OUTCOME

The project demonstrates practical skills in secondary research, M&A transaction data collection, source documentation, data validation, and structured database maintenance relevant to financial market intelligence and transaction research.
